# PrepLoop product brief

## Problem

Interview prep for coding, high-level and low-level system design, and behavioral stories is scattered across tools, so practice becomes uneven.

## Solution

One daily prep loop:

- LeetCode (approach-first + extension sync + AI complexity/tags)
- Random HLD questions
- Random LLD questions
- Behavioral stories with AI proofread

## Non-goals

- Auto-applying to jobs (use Jobright)
- Auto-solving LeetCode
- Replacing Gmail
